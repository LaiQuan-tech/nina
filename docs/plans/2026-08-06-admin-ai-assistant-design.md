# 管理後台 AI 小幫手設計

## 目標

在所有已登入的管理後台頁面右下角加入 AI 小幫手，讓管理員以自然語言查詢 Demo 客戶、報價、工單與回訪資料，並取得可直接用於簡報的營運摘要。

## 安全邊界

- 小幫手只讀取 `is_demo=true` 的示範資料。
- 不接受 SQL、不執行任意資料庫查詢、不直接修改任何資料。
- API 同時通過 middleware 與伺服器端管理員 session／same-origin 驗證。
- 問題最多 600 字、歷史最多 8 則，回覆只渲染純文字，避免 HTML 注入。
- 報表資料先由白名單查詢器建立，再交給 Gemini 潤飾；未設定或呼叫失敗時仍回傳可用的固定格式報表。

## 互動

- 桌機：右下角浮動按鈕開啟 380px 寬側邊對話框。
- 手機：面板接近全螢幕，保留安全區與 44px 以上點擊範圍。
- 初始提供四個快速問題：營運概況、逾期回訪、VIP 客戶、熱門材質。
- 回覆可附帶「前往客戶／追蹤／服務知識」的站內連結。
- 對話只存在目前瀏覽器狀態，關閉面板後保留，重新整理即清除。

## 查詢與報表能力

1. 營運概況：客戶、新客、進行中報價、本月工單、待回訪與逾期數。
2. 客戶名單：VIP、產業、標籤或關鍵字客戶。
3. 追蹤與回訪：逾期、今日與即將到期事項。
4. 服務紀錄：報價與工單狀態、客戶、品項與金額／材質摘要。
5. 材質分析：偏好材質排行與常見需求。

## Demo 可靠性

伺服器會先生成結構化且可核對的安全報表。Gemini 只負責將既有數據整理成自然語言，不可新增數字或客戶。若 AI 暫時不可用，介面仍會顯示相同資料的固定格式版本並標示為「安全報表」。

## 驗收

- 每個管理頁右下角都能開啟與關閉小幫手。
- 快速問題與自由輸入皆可送出，載入中不可重複送出。
- 未登入 API 回 401、跨站請求回 403、過長或不合法內容回 400。
- 回覆數據只來自 Demo 資料，並提供相關管理頁連結。
- Gemini 不可用時仍能完成四種快速 Demo。
- 桌機與手機無水平溢出，鍵盤焦點與 Esc 關閉正常。
